# PsyHome — Psychiatrist Web Dashboard

The web dashboard for **PsyHome**, an AI-assisted psychiatric diagnostic platform. This is the psychiatrist-facing application: manage patients, run AI-assisted diagnostic sessions, and review structured diagnoses generated by the AI engine.

> **Status:** advanced prototype, not a shipped/production product. Built as part of a final-year engineering capstone (PFE), graded *Excellent*.

## Part of the PsyHome Platform

This repo is the web frontend. The full system also includes:
- [PsyHome AI Diagnostic Engine](https://github.com/alaammari69/PsyHome-mental-disorders-diagnosis-api) — LangGraph/FastAPI backend
- [PsyHome Mobile App](https://github.com/alaammari69/psy-home-mobile-app) — patient-facing chat app (React Native / Expo)

## Features

- **Authentication** — psychiatrist login and signup, with role-based JWT auth against the backend
- **Patient management** — searchable, filterable patient list (`AllPatientsPage`), patient creation/edit modal
- **Diagnostic sessions** — create and run AI-assisted diagnostic sessions with a patient (`CreateSessionPage`, `SessionPage`)
- **Diagnosis review** — view AI-generated, structured diagnoses in a dedicated modal (`DiagnosisModal`), including PDF export via `jspdf`
- **Reference page** — browse the underlying DSM-5-derived disorder/symptom reference data
- **Admin panel** — separate admin view for platform-level management

## Tech Stack

- **Framework:** React 19 + Vite
- **UI:** shadcn/ui (Radix primitives) + Tailwind CSS
- **Routing:** React Router
- **Icons:** Lucide, React Icons
- **PDF export:** jsPDF, html-to-image

## Getting Started

### Prerequisites

- Node.js 18+
- The [PsyHome API](https://github.com/alaammari69/PsyHome-mental-disorders-diagnosis-api) running locally or remotely

### Installation

```bash
git clone https://github.com/alaammari69/PsyHome-web-application.git
cd PsyHome-web-application
npm install
```

Set up environment variables:

```bash
cp .env.example .env
# Point it at your running PsyHome API instance
```

Run the dev server:

```bash
npm run dev
```
